# 绑定链与限速恢复

一条绑定链拥有：影视库集合、下载器集合、启用状态，以及上传/下载两套独立规则。链内所有启用影视库的观看数相加，分别计算上传与下载上限。

- 勾选上传限制：只写入上传上限；下载保持下载器原状态。
- 勾选下载限制：只写入下载上限；上传保持上传器原状态。
- 首次接管某方向时保存该方向的原限速。
- 关闭某方向、删除链、禁用/删除下载器或使链失去最后一个影视库时，仅对曾接管方向执行设置中的退出策略。

## 退出策略

设置页面提供“恢复原值”（默认）、“解除限速”（0）、“设为最高限速”（最后启用绑定链的基础速度）。最高限速按上传和下载分别保存，删除绑定后仍可使用。未接管方向不修改；手动“恢复原值”按钮始终恢复接管前值，不受该设置影响。

应用正常停止时也执行该策略；关闭桌面窗口不等于停止应用。强杀、断电不能立即释放；下载器离线时保留接管状态供下次重试。停止时每台下载器默认 3 秒，总恢复预算 20 秒。缺少最高限速快照不会静默解除限制。

删除一个停用绑定链时，如果下载器仍属于其他启用链，则不释放它。限速已等于释放目标时不重复写入、不新增限速事件。

下载器全局限速不能安全地同时由两套规则控制，因此一个下载器不能加入两个启用绑定链；若需切换，请先停用或删除旧链。
