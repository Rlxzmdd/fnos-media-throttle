# 【应用分享】影视观看限速器：有人看电影时，自动让下载任务慢一点

家里的 NAS 经常同时做两件事：一边下载，一边看电影。

没人看电影时，当然希望下载器跑满带宽；但家人一开始播放，下载任务还在全速运行，就可能出现加载慢、拖动进度条卡顿，甚至画质自动下降的问题。

手动暂停下载可以解决，但每次都要自己操作，电影看完后还容易忘记恢复。

所以我做了这个应用：**影视观看限速器**。

它会自动查看当前有多少人在看电影。有人开始播放时，就降低下载器速度，为观影让出带宽；所有人停止播放后，再自动恢复速度。配置一次，后面基本不需要管。

## 它适合什么情况？

如果你遇到过下面这些情况，这个应用应该会比较实用：

- NAS 正在下载时，看高码率电影容易卡顿
- 家里不止一个人在使用影视库
- 不想每次观影前都手动暂停下载
- 希望空闲时下载器全速工作，观影时再自动让路
- 同时使用多个影视库或多个下载器

它并不是简单地“检测到播放就暂停下载”，而是可以根据观看人数逐步调整速度。

例如，你把最高上传速度设为 `7000 KB/s`，每增加一名观众减少 `1000 KB/s`：

- 0 人观看：`7000 KB/s`
- 1 人观看：`6000 KB/s`
- 2 人观看：`5000 KB/s`

还可以设置最低速度，避免下载任务完全停住。上传和下载也能分开控制：只限制上传、只限制下载，或者两个方向都限制都可以。

## 目前支持什么？

影视库：

- 飞牛影视
- Emby
- Jellyfin

下载器：

- 飞牛下载
- qBittorrent
- Transmission

如果一台 NAS 上同时运行了多个影视库或下载器，也可以把它们放进同一条绑定链里统一联动。

## 怎么使用？

整个配置过程可以理解为三步：

### 第一步：告诉应用去哪里看“有没有人在播放”

进入“影视库”，添加飞牛影视、Emby 或 Jellyfin，然后测试连接。

Emby 和 Jellyfin 可以决定是否统计本地 IP 的播放。例如只想对外网播放进行限速，就可以关闭本地播放统计。飞牛影视当前数据库不提供客户端 IP，关闭本地统计时应用会明确提示暂不支持，避免给出错误人数。

### 第二步：告诉应用要控制哪个下载器

进入“下载器”，添加飞牛下载、qBittorrent 或 Transmission。应用默认选择飞牛下载。

使用飞牛下载时，需要填写 fnOS 的**账号名称**和密码。这里填写的是登录账号名称，不是用户 ID。

### 第三步：把影视库和下载器连起来

进入“绑定链”，选择一个或多个影视库，再选择需要控制的下载器，最后设置限速规则并启用。

完成后，应用就会自动工作。首页可以看到当前观看人数，日志里也能查看真正发生过的限速变化。

## 不看电影后，速度会恢复吗？

会。

正常情况下，观看人数回到 0 后，下载器会恢复到规则中的最高速度。你也可以在设置中选择恢复下载器原来的限速。

删除绑定链或退出应用时，也会尝试解除限速，避免下载器一直停留在观影时的低速状态。

为了减少无意义操作，如果计算出的速度和下载器当前限速相同，应用不会重复设置，也不会反复刷出相同日志。

## 安装方法

1. 打开 GitHub Release 页面。
2. 根据 NAS 的处理器架构下载对应安装包：
   - Intel/AMD 设备下载 `linux-amd64.fpk`
   - ARM 设备下载 `linux-arm64.fpk`
3. 打开 fnOS 应用中心，选择手动安装。
4. 上传 FPK，安装完成后从桌面打开应用。

当前版本：`0.9.17`

- [下载 v0.9.17](https://github.com/Rlxzmdd/fnos-media-throttle/releases/tag/v0.9.17)
- [项目主页与源代码](https://github.com/Rlxzmdd/fnos-media-throttle)

## 使用提醒

- 第一次添加影视库和下载器后，建议先点击“测试连接”。
- 设置页可以导出连接配置和绑定链规则；备份包含密码和 API Key，请勿公开分享。运行日志不会写入备份。
- 限速数值没有统一答案，建议根据自己的宽带和电影码率慢慢调整。
- 应用还在持续完善，升级或卸载前建议备份数据。
- 不建议把应用端口直接暴露到公网。

如果遇到问题，可以在 GitHub 提交 Issue。反馈时请说明应用版本、NAS 架构、使用的影视库和下载器，并附上已经遮挡隐私信息的日志或截图。

也欢迎大家提出新的使用场景，以及希望后续支持的影视库或下载器。
