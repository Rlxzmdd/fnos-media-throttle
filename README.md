# fnOS 影视观看限速器

根据影视库的活跃播放数，自动调整下载器的上传、下载限速。观影时为播放留出带宽，无人观看时回到绑定链设定的最高速度。

版本：**0.9.17**（首次公开发布准备）。Go + SQLite + Vue，提供原生 fnOS `.fpk` 安装包。

## 支持与功能

| 类型 | 实现 |
| --- | --- |
| 影视库 | 飞牛影视本地 SQLite、Emby、Jellyfin、通用 HTTP 人数接口 |
| 下载器 | 飞牛下载原生 WebSocket API、qBittorrent Web API、Transmission RPC |
| 绑定链 | 多影视库 × 多下载器；每条链有独立上传/下载规则与启用开关 |

- 观看人数独立轮询；同一影视库可以参与多个绑定链。
- 一台下载器只能属于一个**启用**的绑定链，避免同时覆盖其全局限速。
- 上传、下载可分别接管；关闭方向后只释放该方向。
- 退出、禁用、解绑、删链时可选：恢复原值（默认）、解除限速、设为绑定链最高限速。手动“恢复原值”始终恢复接管前的值。
- 深浅主题、规则小卡片、日志去重与分页；限速不变时不重复写入和报日志。
- 设置页可导出或导入完整配置备份，文件标注应用版本与配置格式版本。

## 安装与部署

1. 从本仓库 **Releases** 下载对应架构的 FPK：Intel/AMD NAS 选择 `linux-amd64`，ARM64 NAS 选择 `linux-arm64`。
2. 可用随包的 `.sha256` 校验下载完整性。
3. 在 fnOS **应用中心 → 手动安装** 上传 FPK，安装后从桌面打开“影视观看限速器”。
4. 升级前备份应用数据目录；上传更高版本的 FPK 升级，不要用同版本不同内容的包覆盖排查。
5. Manifest 最低系统版本为 fnOS 1.1.0；不同 fnOS 版本的私有接口兼容性仍需真机验证。自动构建成功不等于真机安装验收。

应用服务默认监听 `0.0.0.0:18788`。**当前管理 API 没有独立身份认证，请只在可信局域网使用，不要把此端口直接暴露到公网。** 如需远程访问，应自行在受保护的访问入口后部署。

原生安装由生命周期脚本设置 `TRIM_PKGVAR`、`TRIM_APPDEST` 和 `TRIM_SERVICE_PORT`。配置、凭据、原限速及运行日志位于应用私有数据目录，不在源码或安装包中。

## 使用方法

### 1. 添加影视库

进入“影视库”，选择类型、设置连接和轮询周期，然后测试连接。

- 飞牛影视默认数据库路径：`/usr/local/apps/@appdata/trim.media/database/trimmedia.db`，只读访问；应用必须具备相应读取权限。
- Emby/Jellyfin 填服务地址与 API Key；通用 HTTP 接口需返回适配器支持的人数/会话响应。
- “统计本地”控制是否计入本地网络播放。有 IP/本地标志的响应可以过滤；飞牛数据库缺少客户端 IP 时，关闭此选项会明确提示能力不支持，不会假装统计成功。

### 2. 添加下载器

进入“下载器”，默认选择飞牛下载；限速规则在绑定链中设置，不放在连接配置内。

- **飞牛下载**：同 NAS 默认地址为 `ws://127.0.0.1:5666/websocket?type=main`。用户名填写飞牛**账号名称**，不是数字用户 ID；密码用于登录，用户 ID 用于下载业务的用户选择。当前实现不支持 `wss://` 或交互式双因素认证。
- **qBittorrent**：启用 Web UI 后填写 Web API 地址及账号密码。
- **Transmission**：填写 RPC 地址及认证信息。

不要在 Issue 或截图中公开密码、API Key、Cookie、令牌或真实服务地址。

### 配置备份与迁移

在“设置 → 配置备份”中可导出 JSON 文件，包含应用设置、影视库、下载器和绑定链。运行日志不进入备份，导入时也不会清空目标设备已有日志。导入会先按当前释放策略解除已接管限速，校验文件结构与资源关联后，再以单个数据库事务替换当前配置。

备份包含下载器密码和影视库 API Key，请像保管密码一样保管，不要提交到 GitHub 或公开发送。当前速度、采集时间、错误状态和接管前限速快照属于当前设备的临时运行状态，不会迁移；导入后会重新采集并接管。

### 3. 配置绑定链

选择一个或多个影视库、一个或多个下载器，再分别勾选“限制上传”和“限制下载”，设置最大、每人递减、最小速度。

```text
目标限速 = max(最小速度, 最大速度 - 活跃观看数 × 每人递减)
```

界面及新日志显示 `kb/s`，本项目沿用该写法表示**每秒千字节**（1,000 bytes/s），不是千比特。协议层按各下载器要求换算，0 表示不限速。“当前”规则值是根据最近人数计算的目标，实际执行情况以下载器状态为准。

### 4. 释放与异常处理

首次接管前先持久化原限速；写入失败保留原值，下轮重试。删除链或停止接管后执行设置中选择的释放策略，仅操作曾接管的方向。

正常停止应用时会取消并排空写命令，再逐个限时释放。**关闭桌面窗口不等于停止后台应用。** 断电、强杀或下载服务先退出时无法保证即时释放；失败会留存恢复信息和文件日志供重试。不要让多个本应用实例同时控制一台下载器。

影视库采集失败时，绑定链回退到基础速度并记录错误。日志按内容合并，不是逐次操作的完整审计轨迹。

## 观看人数口径

- 有设备标识时，同账号两台设备同时播放计为两个终端；同设备切换多部影片只计一次。
- 缺少设备标识时退回账号去重，不能准确区分同账号多设备。
- 不按影片已播放总时长判断在线：持续更新的播放仍计入；停止更新并超出活跃窗口后移出。
- 飞牛影视默认活跃窗口 60 秒、轮询 5 秒。

## 本地开发

CI 使用 Go 1.26.5、Node.js 24、pnpm 9.15.9。在仓库根目录：

```sh
pnpm --dir app/ui install --frozen-lockfile
pnpm --dir app/ui test
pnpm --dir app/ui build
cd app
go test -race ./...
go vet ./...
go run .
```

在浏览器打开 `http://127.0.0.1:18788`。数据库默认 `db/runtime/throttle.db`；可设置 `DATA_DIR`、`UI_DIR`、`PORT`、`BIND_ADDR`。本地开发建议 `BIND_ADDR=127.0.0.1`。竞态检测需要 C 工具链。

### 本地打包

Linux x86_64 构建机可交叉打包两种 NAS 架构，先安装 Go、Node.js、pnpm，再执行：

```sh
sh scripts/install-fnpack.sh /tmp/fnos-fnpack-sdk
export PATH="/tmp/fnos-fnpack-sdk:$PATH"
sh scripts/build.sh amd64
sh scripts/build.sh arm64
```

脚本下载固定版本的[官方 fnpack](https://developer.fnnas.com/)并验证 SHA-256，使用独立临时目录组装。输出位于 `dist/`，包括 FPK 和校验文件；不提交生成产物。

## 分支与 GitHub Actions

- `dev`：默认开发分支。新代码先提交这里；推送后自动测试并打包，可从 Actions 的 Artifacts 下载测试包。
- `main`：首次初始化后，只有维护者明确确认本次晋级，才创建 `dev → main` PR；不自动合并。
- PR：运行格式检查、竞态测试、vet 和前端测试/构建。
- 发布：版本号与 UI/Manifest 保持一致，在已进入 `main` 的提交上创建 `v版本号` 标签。Actions 验证标签归属与版本，重新构建双架构包、校验，再发布 GitHub Release。普通 dev 推送不发布正式版本。

标签发布命令仅在本次发布得到确认后执行，例如：

```sh
git switch main
git pull --ff-only
git tag v0.9.17
git push origin v0.9.17
git switch dev
```

首次公开仓库创建时 main/dev 从同一份已审核源码初始化。后续协作约定见 [AGENTS.md](AGENTS.md)。
